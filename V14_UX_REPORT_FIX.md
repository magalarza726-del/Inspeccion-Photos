# Inspeccion Photos v14 — UX y Reporte Personalizado

Correcciones realizadas a partir de las pruebas reales en teléfono:

- Panel de Control dividido en dos pestañas principales: Formato de fotos / Formatos de formularios.
- Dentro de Formato de fotos se agregan subtabs: Encabezado, Diseño, Salida y Vista previa. Ya no se muestra todo en una sola pantalla vertical muy larga.
- El editor de tabla de una carpeta es responsivo: en teléfonos cada fila se edita como una tarjeta vertical con los nombres de las columnas; en pantallas amplias mantiene la cuadrícula.
- El Reporte Personalizado ajusta automáticamente título, subtítulo, textos laterales, ruta y celdas para evitar superposiciones o texto fuera de su caja.
- Se eliminan bandas vacías para subcarpetas que no contienen fotos, tabla ni imagen principal.
- Las últimas evidencias de una fila incompleta se centran, manteniendo distribución simétrica.
- El acceso Compartir/Exportar pasa a ser un icono rápido dentro de la carpeta junto a Tabla e Imagen principal.
- Se elimina Exportar PDF/ZIP de los menús de tres puntos.

# Inspeccion Photos v8.3 — logo e icono

- Se incorporó el logo entregado por el usuario como identidad visual de **Inspeccion Photos**.
- El logo se muestra en el encabezado de la aplicación junto al nombre `Inspeccion Photos`.
- El mismo diseño se usa como icono del launcher (`android:icon` y `android:roundIcon`).
- Se generaron recursos mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi y adaptive icon para Android 8+.
- Se eliminó únicamente el fondo blanco exterior conectado al borde para que el logo se integre correctamente sobre el encabezado azul; el diseño central no se altera.
- El logo configurable del PDF sigue siendo independiente, porque representa a la empresa del informe y puede cambiarse desde Configuración.
- No se reintrodujo ninguna marca de MARCA_ANTERIOR.

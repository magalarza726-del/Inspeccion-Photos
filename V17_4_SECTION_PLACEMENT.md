# v17.4 · Posición de secciones

- Añade `SectionPlacement` al formato de Fotos.
- Las secciones pueden colocarse **Encima** o **Debajo** del bloque `imagen principal + tabla`.
- El selector está en **Panel de Control > Fotos > Secciones**.
- La vista previa A4 cambia de orden en tiempo real.
- El PDF del Reporte Personalizado usa exactamente la misma posición.
- La preferencia se guarda en la configuración y se incluye al exportar/importar el JSON del formato.
- Los JSON anteriores siguen siendo compatibles; si no contienen el campo, se usa `Debajo`.

Versión: `3.3.4-section-placement` (`versionCode 334`).

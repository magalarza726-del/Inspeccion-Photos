# v16 — Vista previa mejorada + exportación de Formularios

## Vista previa del formato de fotos
- Vista a escala A4 realista.
- Encabezado con los espacios 3/4 reales.
- Ruta jerárquica de ejemplo.
- Bloque imagen principal + tabla respetando alineación y porcentaje configurados.
- Tabla representa hasta 8 columnas y muestra datos simulados.
- Evidencias simétricas con nombre de archivo y observación.
- Chips resumen de A4, columnas de evidencias, tabla y distribución.

## Formularios
Cada formato de formulario puede seleccionar independientemente PDF, Word y/o Excel.

- PDF: reporte paginado con encabezado y tabla.
- Word (.docx): tabla editable.
- Excel (.xlsx): celdas editables.
- La selección se guarda dentro de cada plantilla.
- Los formularios guardados tienen acceso rápido Exportar.
- Durante el llenado también existe Exportar sin necesidad de finalizar primero.
- Si se eligen varios formatos, se comparten juntos mediante el panel de Android.

Los formatos antiguos migran con PDF activado por defecto.
